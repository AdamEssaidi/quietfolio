# QuietFolio

Personal portfolio of Adam Essaidi, a full-stack software engineer based in Rabat, Morocco.

Designed, customized, and maintained by Adam Essaidi.

## Stack

- Next.js 16
- React 19
- Tailwind CSS 4
- DaisyUI 5

## Run locally

Install the dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production checks

```bash
npm run lint
npm run build
```
